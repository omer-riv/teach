Glossary

The terms this course uses, and exactly what they mean here. Grows with each lesson.

Parameters (weights)
The learned numbers that make up a model. "70B" = 70 billion parameters. L1
Precision (dtype)
The number format each parameter is stored in, which fixes its size: fp32 = 4 bytes, bf16 = 2, fp8/int8 = 1, int4 = 0.5. L1
bf16 (bfloat16)
16-bit floating-point format; the usual precision for released model weights. L1
Quantization
Storing a model at lower precision than it was trained at (e.g. bf16 → int4) to save memory and bandwidth, sometimes at a small quality cost. L1
Host and device
The host is the CPU and its RAM; the device is the GPU and its own separate memory. They are connected by PCIe, which is far slower than the GPU's own memory, so data is copied to the device once and kept there.
HBM (GPU memory, GPU RAM)
The GPU's own memory: high-bandwidth stacks next to the GPU chip on the same package, not on the chip itself and not shared with the CPU. Weights and KV cache must live here while serving. H100: 80 GB at 3.35 TB/s; H200: 141 GB at 4.8 TB/s. Modal glossary
Inference (serving)
Running a trained model to produce outputs for users, as opposed to training it.
Token
The unit of text a model reads and writes, roughly a word piece.
KV cache
The attention keys and values of every token so far, per layer, stored so they aren't recomputed at each step (memoization). Per token = 2 × layers × KV heads × head dim × bytes. Total grows with context length × concurrent conversations. L2
Attention
The step in each layer where the model looks back at all earlier tokens to decide the next one. It's why every earlier token's keys and values are needed. L2
Grouped-query attention (GQA)
Several attention heads share one set of keys and values, so the model has fewer KV heads than attention heads. Shrinks the KV cache by that ratio (Llama 3 70B: 64 heads, 8 KV heads → 8×). L2
Context length
How many tokens a conversation holds (prompt plus output so far). Longer context = bigger KV cache = fewer conversations at once. L2
Node
One server, typically holding 8 GPUs connected by fast links.
